# 0.1 版验证记录（2026-09-29）

## 已验证

- Windows x64 NSIS 安装包构建成功；安装到 `E:\Apps\InterviewCue` 后，独立程序正常启动并显示中文主界面。
- 安装后的程序使用本机 Whisper.cpp Small 与 Ollama `qwen3:4b-instruct`，从系统音频播放中文技术题，无需按键，自动转录、判别并生成三行中文提示。
- 清晰音频的转录为“请解释一下缓存穿透的原理,以及常见的解决方法。”；首个回答 token 距音频播放结束约 1.64 秒。对应原始记录为 `InterviewCue-installed-smoke.json`。
- 一段包含 LoRA 术语的音频被 ASR 错听成“低质适配”。模型未针对这个不确定术语生成错误的确定性回答；对应 `InterviewCue-asr-error-case.json`。
- `npm run build` 通过；包含 CUDA STT 的 Tauri release 构建通过。7 条合成开发样例用于检查结构化接口，但不是独立测试集，不能据此计算触发准确率。

## 当前限制

- 中文夹英文术语的识别仍会出错；换 ASR 模型和术语提示的效果尚未做配对评估。
- 回答仅依赖本地模型知识，没有技术知识检索或事实核验；本次缓存穿透答案基本可用，但不能推论其他问题都正确。
- 同一系统音轨包含双方说话时，当前版本没有可靠的说话人分离。视频测试模式适合先测问题识别与提示流程。
- 麦克风状态目前由音频电平控制提示锁定，尚非 WebRTC VAD。Whisper.cpp 是分块增量识别；可在设置中改选已有的 Sherpa-ONNX 流式模型。
- Laya 没有进入运行路径，第一版采用本地 Qwen 结构化判别。是否换成 Laya，需要独立对话集验证。

## 来源

音频采集、本地 STT 与模型管理底座复用 NexQ 的 MIT 许可代码。该版本是独立应用，不依赖原 NexQ 安装目录。
