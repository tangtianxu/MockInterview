# Windows local maintenance

- The Windows app keeps the internal identifier `app.interviewcue.local` to preserve user settings across updates.
- A tool launched by the MSIX-packaged Codex app can read a private AppData copy under `%LocalAppData%\Packages\OpenAI.Codex_*\LocalCache`. Unrestricted filesystem permissions do not eliminate Windows package virtualization. Matching displayed paths and usernames is insufficient to prove that the desktop app and a tool read the same files.
- For installed-app data inspections, backups, migrations and launches, use the normal Explorer desktop environment. `scripts/invoke-desktop-task.ps1` launches a reviewed local PowerShell task through that desktop process and reads a fresh result file in the shared workspace. Creating a new `Shell.Application` object and calling its `ShellExecute` directly is insufficient; use the actual desktop document's `Application` object, as this helper does. This concerns the Windows package's filesystem view, not a change to security permissions.
- Do not overwrite the user's real `config.json` with a tool-profile copy. Preserve model endpoints, paths, personal material, theme, resume analysis and practice configuration. Back up real user data before migration; verify that the important settings remain identical afterward.
- Question-bank recovery must map source IDs by original path and unchanged content, retain existing source text and extra desktop sources, preserve verification flags and editable answers, then rebuild the local derived index. Use `scripts/repair-knowledge-profile.py` to stage the merge. `scripts/restore-desktop-knowledge.ps1` checks backup/prepared hashes, requires the app to be closed, replaces only the three knowledge metadata/index files, and rolls back replaced files on failure.
- Confirm recovery using a desktop-launched installed process, its native/page records, and the user's actual window when available. An isolated or tool-launched test showing the correct counts is not proof that the desktop instance reads the recovered data.
- Keep profiles, source text, generated questions, backups and diagnostics in ignored local outputs. Do not send private material to a model without authorization for that specific payload. Recovery does not require paid model calls, automatic answer confirmation, or enabling pending drafts.
- The public README describes the simulation practice mode only, as requested by the user.
- Runtime use of an enabled question bank is automatic: matching may send the current question, recent dialogue and candidate metadata to the selected model; synthesis may send selected answers and related passages. The user has authorized this workflow. Explain that scope in the library usage settings and preserve the disable control. Manual analysis/build operations retain their send previews.
