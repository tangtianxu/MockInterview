# 录音复盘与备用模型

## 录一场，再按时间复盘

1. 在「设置 → 音频」确认已勾选「保存本场录音，供历史回放」。新版默认开启；可自行关闭。
2. 选择远程面试、视频测试或线下面试，确认对应音量条有变化，再开始聆听。
3. 正常结束聆听，进入「历史」，点击本场会话。详情直接打开，无需向下翻过整个会话列表。
4. 点击「播放录音」。拖动进度条，查看此刻对应的转录、已识别问题及提示；也可以展开「按时间浏览转录、问题与提示」，点击某条直接跳转。
5. 要保留独立文件，点击「导出录音」保存 WAV。文字记录仍可单独导出 Markdown 或 JSON。长会话点击「继续查看后续记录」逐批阅读。

远程面试：左声道是面试音频，右声道是我的麦克风。视频测试：保存所选系统音频。线下面试：保存所选提问麦克风。录制沿用所选设备，不会改为采集所有设备。软件未开始聆听时不会因此开启录音。

录音在本机应用数据目录的 `recordings` 中，约 230 MB/小时，单场最多六小时。删除会话会一起删除录音。此前版本只有文字，没有保存声音，无法恢复音频；关闭录音后仍保留原有文字历史。中途强制结束程序或磁盘写入失败时，已写入部分可能可播放，详情会提示不完整。

转录时间是片段级，包含识别延迟；问题和提示按处理及显示时刻关联。回放页展示对应提示的最终保存文本，不能把它理解为当时每个字已经全部显示。原始流式转录仍可能听错。

## F8 后直接追问

开始聆听后按 F8，识别题目并生成代码；如 OCR 把符号识别错，可展开识别文字修正，再点「按当前文字重新解题」。随后口述「能优化时间复杂度吗」「为什么这里用哈希表」等追问，问题识别与回答会共同使用当前截图题目和已有解答。

截图附件用于补全指代，当前新问题仍需要由口述或手动提交产生。问到无关的新话题时应忽略附件。截图文字和模型代码可能有误，仍可要求重新检查。新截图或重新解题会替换当前代码题附件；结束本场后清除附件，已有内容保留在历史中。未聆听时先截图，也可以在随后开始聆听的会话中承接该题。

这里的上下文来自本机 OCR 文字及代码，不是把截图图像直接发送给多模态模型。识别用的附件有长度限制；超长内容保留首尾并标记省略，回答生成使用当前附件全文。

## 配一个不同厂商的备用 API

推荐先尝试阿里云百炼的 Qwen；智谱 GLM 也提供兼容接口。模型是否可用、额度及价格以自己的账户为准。

1. 结束当前聆听，打开「设置 → 模型与服务 → 备用 API」。
2. 勾选「主服务异常时自动切换备用服务」，选择百炼或智谱。
3. 点击「获取备用 API 密钥」，在对应平台开通服务、获取密钥，填回软件。它与 DeepSeek 密钥相互独立。
4. 默认模型为百炼 `qwen-plus` 或智谱 `glm-4.7-flash`。可填账户支持的其他模型 ID；需支持聊天流式输出和工具调用，后者用于问题识别。
5. 地址通常已预填。百炼控制台如果提供业务空间专属地址，按控制台地址填写；不把 DeepSeek 的地址或密钥复制到百炼。
6. 点击「保存密钥并检测备用服务」。聊天与问题识别两项检测通过后，再开始使用。检测会有少量 API 调用。

主服务请求报错、没有可用正文、默认 12 秒仍无正文，或正文连续 20 秒没有更新时，自动尝试备用一次。无正文等待时间可选 8–60 秒。正在持续正常输出的长答案不会因为总时长超过 12 秒而被切换；仅有心跳或思考片段不算回答正文。

备用会接收完成当前任务所需的相同问题、对话、截图识别文字及已启用的相关个人资料，按该平台计费。备用服务开始返回正文后，替换主服务的半截结果，重新生成完整答案，避免拼接两份代码。备用也失败时会给出错误，不循环重试；主动取消不会触发备用。不同模型不能保证答案质量相同。

本版备用范围：实时问题识别、口述回答及 F8 解题。资料批量建库、简历分析、模拟出题评分和额外解释继续使用原有设置，不自动改服务。

## 整场录音二次转写

本版先提供录音、回放和时间关联，没有自动再转写整场录音，也没有生成两套转录的差异报告。

后续可接入面向完整录音的 Fun-ASR 或 Qwen 录音文件识别，利用更完整的语境、时间戳和说话人信息复核流式识别。它们是否比本地流式模型更准确，需要用同一段实际录音比较，不能先保证。集成还涉及整段音频发送、费用、说话人对齐和结果保留方式，应独立设计，避免覆盖原始转录。
