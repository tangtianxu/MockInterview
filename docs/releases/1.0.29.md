# MockInterview 1.0.29

## 面试准备与项目练习

- 新增资料库和可编辑题库。支持导入项目文档、报告、幻灯片、表格和源码，按项目准备问答，并保留原文引用。
- 提供两条准备路线：逐个导入项目文件夹，由软件分析；或复制固定说明，让有文件读写能力的Agent先整理，再一次导入。
- 使用指南明确标出资料库、待检查题库和已采用题库各自的步骤，附目录示例、文件格式和读取限制。指南内可直接复制Agent整理说明。
- API生成前预览相关资料、模型及请求范围，确认后发送。生成问答先进入待检查，阅读修改后自行采用。
- 支持手写问题、生成回答建议、修改答案、导入已有问答和历史问题、查找与查重。原来采用的答案不会被新建议直接覆盖。
- 已采用问答可用于模拟练习出题和参考答案，按项目、分类及准备优先级选择。
- 改善重新打开、刷新及保存问答的可靠性，并保持模型、路径、个性化资料及已有问答设置。
- 设置有完整顶部标题栏；面试准备和问答编辑标题栏的非按钮区域支持拖动整个窗口。

## 使用与更新

1. 安装后在“设置 → 模型与服务”连接API或本地模型。API方案不要求安装Ollama；文件文字提取也不依赖Ollama。
2. 打开“面试准备 → 使用指南”，选择一条资料路线。查看文件读取状态后准备问答。
3. 到“待检查”核对答案、引用、个人贡献与完成情况，再采用。模拟练习设置可启用已采用问答出题。

下载本页Windows安装包覆盖安装，已有配置和本地问答会保留。也可从软件的检查更新入口获取；GitHub下载速度取决于网络环境。

软件支持现代Office、OpenDocument、带文字层的PDF、常见文本及源码，单文件不超过64 MiB。扫描件、图片、图表、公式及旧Office/WPS格式仍有读取限制；Agent需要相应OCR或转换能力。模型生成内容应由用户核对。
