# MockInterview 1.0.30

## 问题理解与项目问答

- 问题提取改为原生结构化接口：区分当前发言、近期背景和已有问题，通过片段 ID 引用原文，统一校验新问题、追问、重复和等待状态。
- 追问可以结合近期上下文整理完整任务；包含条件、指代或关系改写时增加含义核验。保留已有的调用间隔与音频停顿调度。
- 已采用题库使用全文 BM25、标题与别名匹配、排名融合和 API 语义匹配，改善口语改述和同一项目多个相近问题的检索。
- 区分“相同问题”“相关问题”“新问题”和“项目不明确”：相同问题读取本机已采用答案；相关问题按新要求组织回答；缺少个人事实时提示补充依据。通用技术问题仍可正常回答。
- 保留标准答案、引用校验和资料发送确认。不会自动采用待检查问答，也不会覆盖用户修改的答案。
- 历史记录可选择显示问题识别和题库检索依据，便于核对原文、处理结果、候选及错误；默认收起。

## 其他改进

- 加入独立的编程题识别与解答界面，支持本机 OCR、题目文字修改、流式代码解答、停止生成及快捷键配置。
- 兼容 API 的问题提取和题库语义匹配需要支持函数调用；连接检测会在需要时检查该能力。Ollama 使用 Schema 结构化输出。
- Windows 安装包继续携带 CPU 语音运行库，并检查可执行文件和附带运行库不依赖 CUDA DLL。

## 更新和使用

下载 Windows 安装包覆盖安装即可，现有模型配置、路径、个性化资料、历史及本地题库保留。软件内的检查更新使用相同的签名安装包；GitHub 下载速度受网络环境影响。

首次使用：连接 API 或本地模型，按“面试准备 → 使用指南”导入资料、生成并核对问答，再启用已采用题库进行模拟练习。

本版已完成本地自动化测试，并使用获得授权的真实转录选段验证问题提取和项目检索。文字选段回放不等同于完整语音链路测试；模型仍可能误解复杂发言。当前检索不依赖额外的向量模型服务，大题库中仅靠语义相似的问法仍可能漏召回。
