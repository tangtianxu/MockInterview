# MockInterview 1.0.31

- 确认、删除提示和文件选择统一留在主窗口内，不再打开独立系统对话框；不会强制显示或激活隐藏的窗口。原来的资料发送确认继续保留。
- 内置文件选择支持常用目录、盘符、名称筛选、文件类型、多选和保存位置选择；覆盖已有文件需要明确勾选。
- 跳过题库匹配、取消资料发送按正常操作处理，不再显示为红色故障。被新问题替代的待确认请求会撤销。
- 修复历史会话尚未提交时，检索依据或模型用量抢先保存导致的外键错误。会话创建失败时不再继续写入孤立记录；真实保存错误仍在窗口内说明。
- 已删除会话的迟到模型结果不会重新建立会话或触发外键警告。
- 软件内自动更新采用静默安装方式，进度与错误留在软件页面中。

覆盖安装会保留现有配置、个人资料、模型路径、历史及题库。Windows 安装包附带签名及更新清单。
