# MockInterview 1.0.37

- 新增本场录音：从开始聆听到结束聆听，本机保存 16 kHz 双声道 WAV。远程面试分开保存面试音频与我的麦克风，视频测试和线下面试只保存所选提问音源。可在音频设置中关闭。
- 历史会话点击后直接进入详情，长记录分批加载。详情新增播放、暂停、前后跳转、进度条、导出录音；点击转录或问题可跳转时间，并查看对应的问题与已显示提示的保存文本。
- F8 截图识别文字、手动修正和生成代码纳入本场共享上下文，问题提取与语义核验均可据此承接追问。附件与当前口述分开处理，旧截图本身不会自动变成新问题。
- 新增独立备用 API 设置，支持百炼 Qwen、智谱 GLM 和自定义兼容服务。主服务报错、空正文、超时无正文或正文停更时切换一次；代码从备用结果重新显示，避免把两个模型的代码拼接。密钥与主服务分开保存。
- 正常主服务回答保留原有提示词、资料、输出预算与显示优化；取消任务不会触发备用调用。切换原因与模型保存在本场处理记录中。

使用说明见 [录音复盘与备用模型](../录音复盘与备用模型.md)。

覆盖安装保留原有配置、资料、题库与历史。录音仅在本机保存，约 230 MB/小时，单场最长六小时；旧历史没有音频，无法补录。时间关联为片段级，回答展示保存的最终版本，不重现每个字的显示动画。本版本没有加入整段录音的二次转写。

验证：原生录音声道与时间、流式超时与取消、备用只调用一次、截图追问协议，以及界面播放/拖动/导出、历史详情与长记录分页。界面测试使用测试音频与模拟服务，不代表已经验证用户未配置的备用厂商账号。
