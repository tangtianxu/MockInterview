# MockInterview 1.0.33

- 问题识别与题库可用性分离。库中没有原题、项目未指定或题库关闭，不再成为不处理问题的原因。
- 回答采用统一的检索增强流程：从已采用问答及资料召回依据，直接流式组织答案；取消日常问答前的目录语义匹配调用。
- 项目概述与比较可以结合多个项目，保留项目与个人职责的对应关系。通用技术题照常解释，不因项目歧义而拒答。
- 未命中、资料失效、索引损坏或读取超时时继续生成；无法确认的个人事实标为待补充。新问题先显示本机答题思路，避免一直留着旧答案；模型接口本身不可用时保留思路并提示连接错误。
- 本机检索最多等待1.2秒，后台读取不占用命令事件循环。发送前若依据已经变更，丢弃失效依据后继续回答。
- 从题目、别名、标签和文件名提取有上限的术语候选，供问题提取及含义核验共同消歧；原始转录保留，不能保证每次语音纠错都成功。
- 保留标准答案的原题直接显示、手动资料分析预览、Python 3标准代码、公式显示、历史与配置。覆盖安装无需重新建库。

资料召回和生成仍可能遗漏或误解细节；模型生成的个人经历应与真实事实核对。本版测试区分文字/模型回放与整场音频测试，不将缓存回放当作语音准确率。
