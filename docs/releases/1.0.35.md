# MockInterview 1.0.35

- 修复远程问答中麦克风持续检测到发言时，新问题及已生成回答可能被一直暂存、无法显示的问题。麦克风仍提供音量及对话上下文，不再阻止新提示显示。
- 历史诊断增加“提示已显示”记录，便于区分问题识别、模型生成和页面提交显示的环节。
- 新增可交给本机 GPT / Agent 执行的个性化配置指南，覆盖简历与项目发现、原资料整理、岗位设置、自我介绍、问答生成导入和实际验证。可在使用指南中保存为 Markdown 文件。
- 使用保存的 PPO 转录、判别及回答进行界面回放，覆盖远程面试、视频测试和线下面试，并检查持续麦克风信号与迟到回答。此测试不调用付费 API，不等同于真实音频重跑。

本版本保留现有应用身份、配置、个人资料和题库。使用同一安装路径升级即可。
