# MockInterview 1.0.38

- 修正备用 API 与录音选项的勾选框宽度和文字对齐。
- 新增回答显示锁定和完整答案前后翻看：默认 F6 锁定/解除，F7 上一条，F9 下一条，也可使用页面按钮。主窗口与悬浮窗同步，后台转录、语义判别、回答生成及保存继续进行；浏览不会重新调用模型。最多保留本窗口最近 100 条完整答案。
- 默认 F4 切换主备 API 的优先顺序，仅对后续实时问题识别、回答和 F8 任务生效，不重答当前任务，原有模型连接和独立密钥保留。
- 所有相关快捷键统一使用单个 F1–F11 并检查冲突（F12 为 Windows 调试保留键）。F8 截图保留，默认 F10 恢复任务栏，默认 F11 退出。设置中可修改显示控制、截图及退出按键。旧版默认组合键迁移为单个 F 键。
- 明确的流式错误即使连接未关闭也立即触发备用，不再等结束标记；同时识别兼容网关返回的 JSON 错误体。无响应默认等待从 12 秒缩短为 3 秒，支持 2–60 秒；默认正文停更 5 秒接替一次。
- 固定显示的文字可在录音时间线中按当时快照复盘。接口地址与模型 ID 的用途已补充到设置和使用说明。

验证包括：锁定时继续接收转录、识别并生成新回答，跨口述/F8 浏览、悬浮窗保持不变、显示操作不增加模型请求、F4 只路由后续任务、密钥作用域隔离、错误帧立即接替，以及原有并行回答与上下文回归。使用模拟服务验证，没有新增付费模型调用。

覆盖安装保留配置、资料、题库和历史；更新后的默认按键请查看设置。详见 [使用说明](../录音复盘与备用模型.md)。
