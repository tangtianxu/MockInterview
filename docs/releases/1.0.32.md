# MockInterview 1.0.32

- 启用题库后，日常问答自动完成语义匹配和相关资料的回答调用，重启或切换问题不再逐题确认。关闭“练习时使用这些问答”即可停用；发送范围在使用设置中说明。
- 模拟练习中的出题、评价和参考答案自动使用已填写的背景，保持问答连续。手动简历分析、批量建库等操作仍可检查发送范围。
- 口述及手动输入的编程、算法实现要求可以生成 Python 3 标准代码答案，保留题目指定的 Solution 类、函数签名或输入输出接口。普通原理题保持简短解释。
- 标准代码包含完整核心逻辑和必要的说明，默认不添加终端程序入口、命令行交互或独立测试脚本。
- 主回答、悬浮窗、模拟参考答案与历史记录统一识别代码块，保留缩进并支持复制；普通公式继续使用原有显示方式。
- 手动题干上限提高到 12,000 字，保留题目末尾约束；回答预算允许完整实现，实际输出长度由题目要求决定。

覆盖安装保留现有配置、资料、问答和历史。模型生成的代码与解释仍需结合题意检查。
